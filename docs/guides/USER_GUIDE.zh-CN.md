# Neuropixels Explorer 用户说明

## 第一次导入：手里的文件放哪里

用桌面 Chrome 或 Edge 打开独立 HTML。从下面两种神经输入中选一种，直接拖到**神经活动与解剖**。看到 Unit 行后就可以看 spike。也可用顶部**导入文件**选择对应类型。

- **一个 NWB 文件。** 把 HDF5 格式的 NWB 2.x 文件拖到神经活动区。优先读取顶层 /units。若分选表保存在 /processing 下，程序可以读取其中唯一的标准 Units 表。查看放电需要表中的 `id`、`spike_times`（秒）和 `spike_times_index`（每个 Unit 的结束索引）。有多组电极时可选组导入。缺少电极、脑区或事件时仍能查看已有 spike。若文件只存原始电压或 LFP，请先完成 spike sorting，再导入分选结果。
- **一个 Kilosort 输出文件夹。** 保留原文件名和目录；每根独立分选的 Probe 各用自己的目录。最低需要等长的一维 `spike_times.npy`（每个 spike 的采样点序号）、`spike_clusters.npy`（对应 Unit ID）以及实际采样率（Hz），可用 `params.py` 的 `sample_rate` 或按提示填写。只有原始电压或 LFP 时，需要先完成 spike sorting。
- **若要看波形、质量或位置。** Kilosort 的 `cluster_group.tsv` 或 `cluster_KSLabel.tsv` 提供质量标签，`amplitudes.npy` 提供逐 spike 幅度，`spike_positions.npy` 提供逐 spike 的 x/y 位置（µm）。查看多通道模板需 `templates.npy`、`spike_templates.npy`、`channel_positions.npy`；保留原有的通道映射和模板索引文件。通道的柄编号来自 `channel_shanks.npy` 或兼容几何表。这些都随同一 Kilosort 文件夹导入。

### 有一列时间，先确定它记录了什么

- **实验事件**（例如声音开始、按键）。NWB 自带的可识别事件可直接在**录制自带标签**中选。给尚无事件的记录补事件时，将 `explorer-events.json` 拖到**录制自带标签**。时间是从神经记录时间原点起算的秒。Excel、任意 CSV 或一列时间戳需要先整理为下面的 JSON。每条事件有唯一 ID；同一种事件重复出现时使用相同的 `type`。同一记录只接收一份事件表，需要合并的事件应在导入前放进同一文件。
- **视频帧与神经记录的对应时间**用于同步。先把 MP4 或 WebM 拖到**行为视频**，选中对应相机。Allen 配套的 `.clock.json`（`allen-video-clock/1`，含匹配的会话和视频指纹）拖到视频标题下的**帧时钟**位置。单列 CSV、TTL 脉冲或原始 `*_timestamps.npy` 不能直接在这里读取。自己实验的视频可点**时间对齐**，填同一可识别事件在视频和神经记录中的秒数。例如同一闪光分别在 10.0 秒和 12.4 秒处，应用后再核对记录后段的另一处闪光。手动单点对齐只校正固定偏移。
- **有效采集时段**（例如中间停采五秒）写到**事件放电 → 高级参数 → 观测区间**。用神经时间秒填写，例如 `[[0,60],[65,120]]`。没有提供观测区间时，分析按窗口内连续采集计算。
- **在视频中标行为**：选中视频，单击**视频标注**新建标签，或把同一视频导出的 `neuropixels-annotations/1` JSON 拖到同一处。只做播放和标注可直接使用视频；用视频标注计算神经响应时需先对齐。

**实验事件文件示例。** 选中一条尚无事件的原始记录后，在**录制自带标签**旁点**下载示例 JSON**，即可得到已填好该记录 `recordingId` 的示例。将示例事件全部替换成真实事件，再拖回同一区域。若自行编写下面的文件，从**数据详情**复制 `recordingId` 替换 `Exp1`。示例表示“神经时间 12.5 秒出现提示，方向为左”。同一神经时钟、同一起点的采样点序号除以实际采样率即可得到秒；其他设备的时间应先与神经时钟对齐。持续事件用 `"kind":"interval"` 并增加 `"end":13.0`。将真实条件写入 `conditions`，同一类型的试次有两个不同值时可进行条件比较。

`{"schema":"neuropixels-events/1","timebase":"neural_seconds","recordingId":"Exp1","events":[{"id":"cue-1","sourceId":"1","sourceKind":"experiment","type":"cue","kind":"point","start":12.5,"conditions":{"direction":"left"}}]}`

### 有脑区图或坐标，先确定它对应什么

- **每个 Unit 已有脑区或位置。** 对于 Kilosort，尤其记录名称不带实验编号或多个 Probe 都有 Unit 7 时，可在每个记录文件夹各放一份 `explorer-units.json`，随该文件夹拖入。示例 `{"units":[{"cluster_id":7,"brain_region":"CA1","x_um":16,"probe_depth_um":320,"shank_id":0}]}`。只知道脑区时只填 `cluster_id` 和 `brain_region`。核对一个已知 Unit 的 ID 和脑区。Allen NWB 已有对应脑区时直接使用文件内信息。
- **已有按 Unit 列脑区的 CSV。** 例如文件夹名 `Exp1`，表头 `experiment,cluster_id,region`，下一行 `Exp1,7,CA1`。把 CSV 拖到 **Probe** 或**神经活动与解剖**。当前 CSV 匹配会从名称提取实验数字；多条记录共享数字与 Unit ID 时请使用上面的逐记录 JSON，避免把不同记录混在一起。
- **探针沿深度经过的脑区。** 准备逗号分隔的 CSV，每行一个测量位置。表头 `experiment,shank,depth_um,region`，示例行 `Exp1,0,320,CA1`。拖到 **Probe** 区，核对对应柄的脑区色带；深度单位是 µm，零点、方向、柄编号必须与信号数据一致。PNG、PDF、组织切片或只有脑区名称的图片需要先整理成 Unit 对应表或已配准的深度表，才可关联到信号。

### 怎么确认导入成功

先点一行已知 Unit 核对 spike。打开**事件放电**，选一个重复事件并运行；点热图中一行，右侧应显示该 Unit 的逐次 spike，每次事件起点对齐到 0 秒。点其中一次应回到原始神经时间，有同步视频时同时核对画面。要找响应相似的 Unit，可在热图上选择**按响应形状分组**。打开**项目文件与功能**可逐项检查当前记录识别了哪些输入。

## 信号与分析操作

信号和分析共用顶部标签栏。 标签多时会自动缩短。悬停可看全名，在标签栏滚动可左右翻页。右击 Unit 可添加或取消「感兴趣」标记。在「设置 → Unit 标记」可命名更多标记并选择颜色。保存项目会一起保存对各 Unit 的标记。普通 Probe 图可点选定位 Unit。在「事件放电 → 分析哪些 Unit → 在 Probe 图上选择」中，可以框选或圈选 Unit。圈选时只画指针经过的轨迹，松开后选中范围内的 Unit。框选或圈选时，按住 Shift 再用左键拖动即可平移放大的图。Ctrl 拖动可追加，选择模式下单击空白可清空。右上角的“平移”可拖动放大的图。“缩放”模式下单击放大，Shift＋单击缩小，拖框可放大框内区域。滚轮以指针为中心缩放，100% 恢复全图。Probe 和 spike 选择区都可拖动右边、下边调整宽度或高度，拖右下角可同时调整两者。要继续从另一支 Probe 选 Unit，可直接使用分析页里的 Probe 下拉框。

打开「事件放电」，先选事件标签和要看的 Unit。事件时间范围决定纳入原始记录的哪几次事件，可用整条记录、已有信号选区，或填写起止秒。响应窗决定每次事件前后显示多久，例如 −0.5 到 1 秒。运行后，热图每行一个入选 Unit，0 秒表示事件开始。要调整这次分析，从结果上方重新展开设置即可。点热图中的一行，旁边就会显示这个 Unit 每次事件的原始 spike。每行是一次事件，每条短线是一个 spike。点某次事件可回到原始记录，有同步视频时也会跳到对应画面。点分析标签即可回来。

热图、组平均曲线和逐次 spike 共用相对时间轴。竖线的 0 s 是所选事件每一次的开始。例如 −0.2 s 都表示该次事件开始前 200 毫秒。逐次图左侧的秒数是这次事件在原始记录中的时刻，点击该行即可跳回。

新分析默认合并事件。命中、漏报来自你选择的标签和时间窗。要用两个标签判定 Hit / Miss，先选对齐事件，再在「按条件比较」选择双标签判定和响应标签。高级设置中的匹配窗默认从事件后 0.15 秒到 0.75 秒，包含起点。逐次 spike 图用菱形标出同一对齐标签的其他起点。勾选「排除窗口内再次出现同一标签的试次」并重新运行，可只看窗口中该事件单独出现的试次。

选好两个条件并运行后，在事件响应结果的「逐次查看」旁点选 5J–5M。5J 的两张热图逐行对应，可按参照条件分组。5K 叠加同组的两条 Hz 曲线，悬停可读差值。5L 显示同一批 Unit 在两次所选事件里的 spike。点试次跳到原始记录和视频，再点原分析标签页就能回到刚才那两次试次。5M 按输入的毫秒窗连接同一 Unit 的两个放电率，可另加事件前基线。点「逐次查看」可回到单个 Unit 的逐次 spike。「导出 PNG」保存当前图的白底版本。

想找响应形状相近的 Unit 时，点「按响应形状分组」。默认分析当前事件类型的所有合格试次。比较时选择数据中实际存在的条件字段（例如方向），再选两个值。第一组作为参照；切换两组时保留组员与行序。可展开计算过程查看事件对齐、分箱和分组。

需要限制 Unit 或时间时再展开分析设置。可按脑区、深度、手动 ID 或 Probe 图选 Unit。高级参数可调整时间窗、分箱宽度和试次对半检查。图表配色随主题切换，保存的 PNG 始终为白底。

## 1. 用途与科学边界

Neuropixels Explorer 在本机读取 Kilosort 分选输出和兼容的电生理 NWB，供研究者查看 Unit、放电时间、放电率与事件响应。位置、模板和脑区视图使用所导入记录提供的数据。

逐 Unit 检查时，可结合实验设计解释质量标签、不应期违规率、污染估计、波形与解剖标签。脑区可来自 NWB 电极位置的区域标签、逐记录 Unit 元数据或兼容的脑区表。缺少映射的 Unit 显示“未映射”。

## 2. 创建、保存和打开项目

视频标签页上的 × 关闭该视频。「项目 → 撤销关闭视频」可恢复机位、帧时钟和标注。切换 Probe 会保留当前机位的行为标签。拖动数值框右侧的横向手柄可连续调整，点上下箭头可微调，点数值可直接输入。播放器按钮旁会显示当前快捷键。标签设置里，点「＋ 新标签」建立名称，「保存」写入编辑，「选用标签」返回播放器；也可双击已有标签直接使用。

将文件拖到对应区域。若有文件类型与区域不符，整次拖放都会被拒绝，红色提示会指出正确位置。多种类型可以一起拖到页首或通过**导入文件**打开。「设置 → 字号」可直接输入 14–24 px，也可用上下方向键每次调整 1 px。把帧时钟 JSON 拖到视频标题下方的同名提示，也可点击选择。验证后原处显示绿色状态。把缺少的 Kilosort 文件拖到神经活动或 Probe 内写有该文件名的位置。录制事件 JSON 可拖到「录制自带标签」。打开视频后，点击「视频标注」区域新建标注，点「＋ 新标签」后再填名称、选颜色和事件类型。将已有标注 JSON 拖到同一区域即可导入。也可以先拖入 JSON，再添加匹配的视频。桌面默认左右布局，手动切换会被记住。单独拖视频即可播放和标注。Kilosort 可以分次补齐，神经活动区会显示现有数据及缺失文件。一次导入多条同名结构的记录时，请保留各自的文件夹。项目菜单保留传统分组导入。

| 拖到哪里 | 应该选什么 | 导入后可以看什么 |
| --- | --- | --- |
| 神经活动区 | Kilosort 结果文件夹，包含 `spike_times.npy`、`spike_clusters.npy`，采样率来自 `params.py` 或手动填写 | Unit 和放电时间，及文件中已有的模板、通道和质量标签 |
| 神经活动区 | 含已分选 Unit 的 NWB 2.x HDF5 文件 `.nwb`，多组记录可任选一组或多组 | Unit 与放电，文件中可识别的脑区和事件 |
| 视频区 | 同次采集的一个或多个行为视频，如 `side.mp4` 或 `.webm` | 切换相机、逐帧查看与标注 |
| 视频的时间对齐区 | 该视频的 Allen 帧时钟 JSON，如 `side-full.clock.json` | 视频帧时间与神经时间的对应关系。缺少时钟也可以看视频，或用两边都能识别的时刻手动对齐 |
| 视频标注区域 | Explorer 视频标注 JSON，或兼容的行为候选片段 JSON | 完整标注文件会恢复其中的草稿，候选文件会追加片段。两种导入均可撤销 |

视频建议使用 MP4 / WebM；MOV / AVI / MKV 取决于浏览器的解码支持。本界面读取分选后的放电结果，原始采集数据需先完成 spike sorting。

导入后查看**项目文件与功能**：活动图、区间空间活动分布、Unit 模板、脑区、视频标注和时间对齐分别打勾或叉，并说明需要的文件。可以先用已具备的功能，随后补充视频。Allen 电极坐标可用于空间活动分布，但不提供 Kilosort 多通道模板。选择已入库的同一个 Kilosort 文件夹时，保留目录中已有的脑区信息。

点击**保存项目**保存数据、视频、对齐关系和标注。把项目包拖回页面即可恢复。项目菜单中的**最近打开**可读取旧版本地缓存。本地服务的 `.neuroproject.json` 引用原始文件。

同一份 NWB 可以一次打开多根探针。点亮所需探针，再点「使用所选探针」，每根探针对应顶部一条记录。点标签上的 × 从当前项目移除这条记录。可在项目菜单撤销移除。

可继续将属于同次采集的视频拖进视频区，将其他探针拖进神经区。视频标签页可搭配任何一根探针，每个视频保存自己的标注与对齐。已有多根探针时加入第二个视频，或已有多个视频时加入第二根探针，需确认属于同一项目。将对应帧时钟 JSON 拖到当前视频的对齐区，可覆盖其手工对齐。

视频的逐帧按钮前后移动一帧。点击视频区后，左右键前后移动五帧。提供完整视频帧时间表时按实际帧号跳转。只有稀疏同步锚点时，使用文件或帧时钟声明的帧率。缺少帧率时按 30 fps 估算。

右键信号行可以对比或深入检查这一行的 Unit，已有选区时还能放大或清除选区。右键视频画面可以标记行为、放大画面或添加视频。键盘聚焦记录标签、Unit 名称或视频画面后，按 Shift+F10 打开同一菜单，Esc 返回。

## 3. 在记录中查看多个 Unit

打开记录后显示整段信号。每个 Unit 行上部显示原始 spike，下部显示同一时段的分箱发放率。面板显示绝对起止时间、窗宽 Δ、Hz 范围和分箱宽度。右侧滚动条按解剖顺序浏览 Unit；底部全程条显示当前窗口在整条记录中的位置。

- 点 Unit 左侧卡片上任意位置即可选中。按 Ctrl/Cmd 点其他卡片追加参考行，再点任一高亮卡片移除该行。主 Unit 使用实色底，参考行使用双线边。滚出视口的高亮行固定在顶部。移除最后一行保留窗宽、游标、选区和视频位置。要看波形与质量指标，打开「深入检查 Unit」。
- 向左拖卡片可让信号左移，查看较晚的时段。拖动底部滑块可保持窗宽平移。单击底部秒刻度或全程条，用两秒窗查看点击的时间点。记录边缘处以可用范围为准。
- 点信号定位共享游标，横拖信号选出区间。可选「放大到选区」或「找相似片段」。Ctrl/Cmd + 滚轮围绕指针缩放。放电密集时一个像素可能包含多次 spike。

图右上角可切换测量、手形平移和框选放大。拖动时按 Esc 放弃本次手势。悬停在 spike 上可读原始时间，悬停在放电率轨可读分箱范围、计数及 Hz。放大模式下滚轮围绕指针缩放。房子恢复整段记录，后退和前进只切换时间窗。点信号后按左右键平移。点视频后按左右键前后移动五帧，空格播放或暂停，M 按当前类型标记时间点或开始／结束持续事件。帮助旁的「设置」可修改这些键、字号、语言和配色。右键可保存项目或将当前视频标注另存为 JSON。

行为对齐面板的后退和前进恢复参考事件、Unit 和检索条件。标注编辑器的撤销恢复标注内容。浏览器单文件版的「项目」菜单可撤销和重做当前项目内各记录最近八次视频更换与时间对齐。

### 深入检查器中的 Unit 列表

先在横向记录栏选择一条记录，再使用左侧神经元单元列表：

- **单击**：只打开这个神经元单元，替换当前信号。
- **Ctrl + 单击**：保留已打开信号，并追加这个神经元单元。
- **右键**：打开菜单，可选择**仅打开此单元**、**添加到当前视图**、**从视图移除**或**在探针上定位**。
- **方向键上/下**：在列表中移动键盘焦点。

单击任何已打开的信号，就会把它设为当前聚焦的神经元单元。左侧列表会自动滚动并高亮对应行，探针检查器与下方详细图也会同步切换。当前最多可同时打开十个神经元单元。

列表中的 `Good`、`MUA` 等值是 KiloSort 或人工整理标签。

## 4. 阅读深入检查器中的信号

每个已打开的神经元单元都有两个对齐的视图：

- 上方放电栅格图用竖线标出单个放电事件的时间。
- 下方曲线显示经过时间分箱的放电频率。

底部概览图压缩显示整段记录，其中的描边框就是上方详细图正在显示的时间段。单击或拖动概览图可以移动详细时间窗。

### 光标模式

把鼠标移到信号上可读取时间，但不会改变视图；页面滚动保持正常。

### 缩放模式

在信号任意区域拖框选择时间段，或用滚轮以鼠标位置为中心缩放。只有当鼠标位于信号内部时才会拦截滚轮；网页其他区域仍然正常上下滚动。

### 平移模式

水平拖动可移动时间窗。鼠标在信号内部时，向下滚动移动到更晚时间，向上滚动移动到更早时间。触控板会使用横向与纵向输入中幅度更大的方向。

### 时间联动与时间独立

**时间联动**会把缩放、平移、返回和重置同步应用到所有已打开的神经元单元。**时间独立**只操作当前聚焦信号。直接做时间对比时使用联动；需要单独放大某个信号时使用独立。

### 同步行为视频

紧凑视频轨道位于神经信号正上方。如果当前记录目录中包含受支持的视频文件，Explorer 会在本机直接打开。也可以使用**连接本地视频**选择其他文件；无法取得受保护的实验室视频时，使用**生成验证视频**。生成的小鼠场地视频是确定性的：帧率固定为 30 Hz，显示准确帧号，并且每五秒出现一次可见同步脉冲。

可以播放、暂停、拖动、改变速度，也可以逐帧前进或后退。启用**跟随信号**后，当前神经时间会保持在可见窗口内。绿色“视频”游标会在所有已打开神经元单元上标出完全相同的神经时间。在光标模式下单击神经图，会反向把视频定位到该时间。

映射状态会区分已验证的逐帧时钟和未验证的手动偏移。修改**偏移（秒）**后，状态会明确变成**未验证 · 手动偏移**。真实实验只有在提供逐帧时间戳、TTL 事件或有来源记录的时钟拟合后，才能标为已验证。

## 5. 解释神经元单元详情

- **放电事件**：分配给该神经元单元的检测事件总数。
- **平均放电频率**：整段记录平均每秒的放电事件数。
- **ISI < 2 毫秒**：相邻放电间隔小于 2 毫秒的比例；可与波形和污染估计一起用于质量检查。
- **时间覆盖率**：记录各时间段中能检测到该神经元单元的比例。
- **KS 幅度**：KiloSort 给出的幅度摘要，其单位依赖当前数据集。
- **KS 污染率**：KiloSort 提供的污染估计（如存在）。
- **幅度稳定性**：相对放电幅度随记录时间的变化。
- **自相关图**：同一神经元单元不同放电事件之间时间差的分布。
- **KiloSort 模板**：最常分配给该神经元单元的模板波形和峰值通道。

这些功能旁边的问号会说明“是什么、怎么看、什么时候使用”。可以用鼠标悬浮，也可以用键盘把焦点移到问号上。

## 6. 使用探针检查器

右侧面板明确分成四层：

- 脑区色带是可选映射文件提供的连续深度区间。
- 淡色通道刻度表示电极采样位置，不是主要交互对象。
- 灰色圆点表示尚未打开但可用的神经元单元。
- 彩色圆点表示已打开的神经元单元，其颜色与中央信号一致。

当前聚焦单元带白色外环、水平深度线和固定标签。鼠标悬浮在标记上可查看神经元单元 ID、物理探针、shank、深度、脑区和通道。单击可锁定标记及其深度；单击 shank 空白处或按 **Esc** 取消锁定。若多个神经元单元在相近深度重叠，Explorer 会弹出一个小列表，而不是让用户猜测圆点含义。

探针上的选择规则与左侧列表一致：单击仅打开，Ctrl+单击追加，右键打开共享菜单。“附近神经元单元”以锁定的探针位置为参考，以微米显示距离。

当前采集中的 `channel_shanks.npy` 表示一根物理探针上的四个 shank。因此检查器显示一个可展开的**探针 1**，其中包含 **Shank 1–4**，不会再把它们标成四根物理探针。未来如果数据确实来自多根探针，必须在 shank 身份之外再提供明确的物理探针身份。

## 7. 脑区映射

KiloSort 输出本身不包含可靠的脑区身份。解剖注释必须作为独立的可选数据提供。兼容的深度映射至少需要：

- `probe` 或 `shank`
- `depth_um`
- `region`

建议同时提供 `electrode`、`atlas_id`、`color`，以及用于特定记录轨迹的 `recording_id`。`MPN` 等脑区缩写和 KiloSort 字段名会按原文件显示，不进行翻译。

当前映射属于电极/深度级元数据。除非提供完整的图谱坐标与配准来源，否则它不等同于经过配准的三维 Allen CCF 轨迹。

## 8. 布局、主题、语言与键盘操作

拖动左侧分隔条可调整神经元单元列表与信号工作区的宽度。探针检查器保持固定宽度，因为横向变宽不会改善深度辨识度。拖动探针图下方的横向把手可以调整图的高度；把手获得键盘焦点后，使用上/下方向键小幅调整，按住 Shift 可大幅调整，按 Home 重置。小屏幕仍可用箭头按钮折叠侧栏。

主题包括深色、浅色、高对比度和跟随系统。主题会同步影响 HTML 界面、信号 Canvas、探针色带、网格、选择框和神经元单元颜色。主题与语言选择都会保存在当前设备。

Explorer 支持 English、简体中文和 Español。切换语言会同时更新界面、问号说明和帮助抽屉。文件名、脑区缩写与 KiloSort 字段名保持不变。

使用 **Tab** 和 **Shift + Tab** 在控件间移动；按 **Enter** 或**空格**激活按钮；按 **Esc** 关闭帮助、菜单、数据状态或已锁定的探针选择（适用时）。

## 9. 隐私与性能

在文件夹模式下，所选文件保留在本机。浏览器只负责索引文件夹；后台处理完成后，界面只接收所选神经元单元的结果。数据库模式可以连接独立运行的本地服务，但它是可选的，直接以 `file://` 打开 `index.html` 时不需要该服务。

帮助说明以 Markdown 保存在仓库中，并在发布前预编译成本地 JavaScript 内容。帮助抽屉不使用 CDN、在线 Markdown 服务或网络请求，因此直接打开 `index.html` 时也可使用。

## 10. 常见问题

- **没有发现记录**：检查每个候选目录是否包含 `spike_times.npy`、`spike_clusters.npy` 和 `params.py`。
- **某个图不可用**：打开数据状态，检查对应源文件是否缺失。
- **脑区显示未映射**：确认文件夹中包含兼容的 Legacy Table 或深度映射，并且记录/神经元单元标识一致。
- **无法查看原始电压**：KiloSort 输出文件夹常只引用外部 `continuous.dat`；Explorer 目前只提供版本化 provider/reader 扩展端口，没有注册 Raw Voltage 实现，也不会把放电时间误标为电压。
- **没有实验室视频**：使用**生成验证视频**即可在不创建、不复制受保护数据的情况下验证播放和准确对齐。
- **导航操作了错误的信号**：检查当前是时间联动还是时间独立，以及哪个信号处于聚焦状态。


## 11. 行为标注测试版

播放器的进度条始终覆盖整段视频。拖动会暂停并定位视频。条上缘的短线和色段对应当前来源、当前类型的事件，点标记可定位该事件。进度条上方的「事件标记」默认收起。点标题可展开，进入「编辑片段」也会自动展开。点 ＋、− 或在指针处滚轮缩放，放大后按住 Shift，在事件轴上用左键左右拖动或滚动滚轮即可平移。「全程」恢复完整范围。调整事件条比例会保留视频位置和神经时间窗。

有关联视频时，两条都显示视频秒。录制标签按照原始神经秒映射到视频，覆盖范围外的点不显示，跨边界区间只画相交的部分，源事件的起止时间保留。没有视频时，事件条按录制的神经秒显示。

在「标签设置」点「＋ 新标签」，填写名称、选择颜色和默认事件类型，再点「保存」。双击已保存的标签即可选用。记录首次接触的一瞬间，在播放器的「标记」旁选「时间点」，点一次即记下当前视频时刻，播放或暂停状态照旧。记录一段理毛行为，选「持续事件」，点「标记」开始播放，点「停止」暂停并保存起止时刻。Esc 取消未完成的持续事件。切换类型会设置当前标签今后标记的默认类型，已有事件保留原类型。

展开「事件标记」，拖动视频标注可移动时段，选中后拖边缘可调整起止时间。在事件行的空白处拖动可框选多条，按 Delete 删除。拖上方秒刻度可左右平移。「标签设置」列出每个名称下的事件，可以逐条删除，也可确认删除该标签在各个方案下关联的全部事件。「撤销删除」或 Ctrl+Z 可恢复，Ctrl+Y 可重做。在「编辑片段」中按住 Alt，从事件行的空白处拖动可画一个新时段，再选名称并点「保存标注」。悬停可预览帧；选中已保存的片段后可播放该段，拖动手柄或把边界设在播放游标处。「精细调整」可输入秒数或从 0 开始的帧号，结束帧不包含在区间内。帧号按标称 FPS 换算，变帧率视频请用秒数。视频角落、片段和神经信号遮罩共用标签颜色。「片段工具」提供新建、拆分与移除，批量审阅在「片段与分组」中，编辑支持撤销与重做。左右拖动 Speed × 的手柄可按每像素 0.01 调速，按住 Shift 为 0.001，也可点击输入。

### 查找行为标签附近反复出现的活动

选择录制标签或视频标注，点「同类事件放电」，选择要看的 Unit。每行是标签的一次出现，零点默认是事件开始。点行首的时间可回看原始信号和对应视频。下方的重复放电条显示，同一时间格内有多少次事件出现过 spike。统计时每个行为串最多取一次，并跳过相互重叠的窗口。

想找相似片段时，在某个 Unit 的一行上横拖指定参考时间段，也可选重复放电条给出的真实代表事件。搜索会比较相同 Unit 在参考和候选片段内逐格的 spike 数。点候选可将两段原始放电放在同一时间尺度上查看。也可在「神经活动与解剖」框选一个片段直接搜索，从已高亮的对比行开始框选时使用所选 Unit。

区间统计：在视频时间轴或神经信号上方的彩色行为片段带选择已保存片段，
也可以在信号区域任意拖选时间，再点击左侧 Probe 的 **Interval distribution**。
点大小表示区间 Hz；列表包含全部 Unit 的 Hz 和 spike 数。深度—Hz 统计图默认竖向，
**Horizontal view / Vertical view** 切换坐标轴方向，数值不变；悬浮点可查看详情。
缺少深度的 Unit 仍保留在列表。面板展开时跟随新选区更新，关闭保留选区。
此统计需要本地项目，使用实际覆盖的神经时长和 `[start, end)` 半开区间。

**实验性自动分组** 在本机按运动和画面特征生成候选，可能受位置和光照影响，
尚未验证为可靠的行为识别。选择一组并比较样本视频，再命名分组、确认所选

“未验证”提示，原始视频和神经数据不会被修改。

## 同时查看两类 Probe 分布

选中行为片段或拖选神经时间段后，打开 **Interval distribution** 查看该区间的 spike count / Hz。
在神经视图、Probe 或统计列表中选择 Unit，再打开 **Unit 模板分布 / Unit template distribution**。两个区域可同时展开，在左侧滚动查看。
模板图的圆点表示电极位置，大小表示该通道的模板峰峰值；点击电极或使用“选择通道”查看波形，各通道使用同一幅值尺度。全部通道列表保留通道行号、可用的采集通道 ID、坐标和幅值。

## 可选模型特征与本地帧示例

在 **编辑片段 → 片段与分组 → 模型特征 / 关键点** 中导出模型输入 JSON，再导入带时间的特征/关键点 JSON，进行分组和审阅。**运行像素适配器示例（前 30 秒）** 用真实视频的 RGB 均值演示可选的源码模型接口，不是训练好的行为识别器。它需要本地文件或浏览器项目视频 Blob，使用当前分组设置。结果始终待审阅；保存项目会保留特征、模型及输入来源和人工修改。取消、关闭编辑器或换源会丢弃待完成结果。基础工作流不需要模型或 Python；此面板不加载任意脚本或远程模型。

## 群体动力学

从「新分析… → 群体动力学」打开分析，选择原始 Unit ID、连续神经起止时间和分箱宽度。计算在可取消的 Worker 中运行，在训练段拟合 PCA 与预测模型，并比较验证/测试误差。点击轨迹点或选择分箱，再点击“在信号 / 视频中查看该分箱”，即可返回共享时间视图。先将分析保存到项目，再导出可迁移项目包。未知采集覆盖保持提示；受限线模型人为约束一个特征值为 1。此路径无需行为标签或 Python。
