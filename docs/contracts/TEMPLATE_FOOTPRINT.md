# Unit template distribution

Version: 4.5.0-beta.1. The Unit template distribution and interval activity
distribution are independent panels in the linked neural/video/Probe workspace.
Select a Unit, then open **Unit template distribution**. Select a clip or drag a
neural interval, then open **Interval distribution**. Both can remain open.

Changing Unit preserves the time selection and exact interval statistics.
Selecting a template channel changes only the local waveform, not the Unit or
time context. Changing Recording discards old template and pinned comparison
content. The Probe sidebar scrolls while neural activity and video remain visible.

## Data and meaning

The compatible `templateFootprint` field in Unit review is generated by
`scripts/kilosort-core.js::buildTemplateFootprint` in folder mode and
`server/neuropixels_explorer/template_footprint.py` in indexed mode.

- Select spikes by `spike_clusters.npy`, then count their `spike_templates.npy`
  assignments. Choose the most frequent template; ties select the lower ID.
- Report `templateId`, `templateCount`, `templateSpikeCount`, `unitSpikeCount`,
  `sampleRate`, `sampleCount`, `peakChannelIndex`, `scope: recording_template`,
  `amplitudeUnit: stored` and `source: templates.npy`.
- A merged Unit may contain multiple templates. The displayed dominant template
  is not claimed to be the mean waveform of all the Unit's spikes.
- Dense templates have shape `[template, sample, channel-row]`. Channel rows join
  directly to `channel_positions.npy`; `channel_map.npy` gives original acquisition
  IDs, not another permutation to apply to coordinates. Optional plural
  `templates_ind.npy` must contain a dense identity row. Sparse/non-identity
  layouts return `unsupported_layout` instead of guessing the mapping.
- Channels return `index`, optional `channelId`, `xUm`, `depthUm`, optional
  `shankId`, `peakToPeak` and `waveform`. Missing coordinates stay null and omit
  that channel from the map; its waveform remains in the selector/list.
- Marker size encodes each channel's stored peak-to-peak amplitude. Channel
  waveforms share one amplitude scale. Time starts at the template's first sample
  in milliseconds; it does not imply an event-aligned spike time origin.

These are **whole-recording representative, stored template values**. No
unwhitening, microvolt calibration, source-data modification, cell localization
or within-interval raw waveform extraction is performed. No template is generated
for Allen NWB adapters that lack one. Missing templates/assignments/geometry,
invalid values or unsupported maps return explicit statuses with no channels.
Interval firing rates continue to use exact spike counts / covered seconds.

Sources: [Kilosort exported arrays](https://kilosort.readthedocs.io/en/latest/export_files.html)
and [Phy dataset contract](https://phy.readthedocs.io/en/latest/dataset/).

## Checks

`node tests/validate-template-footprint.cjs` checks assignments, ID tie breaking,
channel identity, exact values, C/Fortran order, missing/invalid inputs and renderer
geometry. `python -m unittest discover -s tests/python` includes the service and
NumPy path. Interval, pinned-comparison and synchronization checks remain separate.

2026-10-21: 40 Python tests passed. Chrome exercised the real 103-Unit/384-channel
Kilosort recording with an explicitly synthetic video, both panels, retained
intervals, Unit/channel selection, two pins, inspector return, keyboard controls,
annotation context and Recording reset. Folder Worker loading also passed.
Independent source-array comparisons matched all channels for Units 0, 1 and 40.
Screenshots at 1920×1080 and 1280×900 were inspected. This is engineering evidence,
not user layout acceptance, real-video synchronization accuracy or scientific validation.
