# Neuropixels Explorer 用户说明

## 1. 用途与科学边界

Neuropixels Explorer 是一个本地优先的 KiloSort 输出检查工具。它帮助学生和研究人员查看神经元单元（Unit）、放电时间、放电频率、KiloSort 模板、物理探针位置，以及可选的脑区注释；研究数据不需要上传到网络。

Explorer 用于人工检查，不是自动给出生物学结论的系统。质量标签、不应期违规率、污染估计、波形或解剖标签都必须结合实验设计和其他证据解释。KiloSort 提供放电与几何数据；脑区标签来自独立的 Legacy Table 或兼容映射 CSV。没有脑区文件时，程序会明确显示“未映射”，不会自行推断。

## 2. 打开数据

单击**打开文件夹**，或把完整的项目/实验文件夹拖到开始页面。该文件夹可以包含多个 KiloSort 记录目录。程序会索引全部候选记录，但只有在打开某个神经元单元时才读取大型 NPY 数组。

加载后查看**数据状态**，其中分为：

- **可用**：已在记录中检测到的核心输入。
- **缺失**：至少一条记录中缺少的核心输入。
- **无效**：未通过结构检查的候选记录。
- **可选**：脑区注释与探针—脑区轨迹。
- **数据流 / 扩展接口**：同步视频可用状态，以及未来 Raw Voltage 读取器的注册状态。

对于每一个缺失的核心输入，**数据状态**会列出受影响的记录和准确文件名。选择**添加文件**可补充一个或多个文件，选择**添加文件夹**可补充整条记录的文件夹。Explorer 会拒绝属于其他记录的文件、与现有资源冲突的替换、重复候选文件，以及 shape 不兼容的 NPY 数组。补充失败时，数据库目录和托管文件都不会留下半套结果；补充成功时，只刷新受影响的记录，并保留已打开和当前聚焦的神经元单元、时间窗口、导航历史及三栏布局。

文件名和 KiloSort 字段名，例如 `spike_times.npy`、`channel_shanks.npy` 和 `depth_um`，在任何界面语言下都保持不变。

## 3. 选择与对比神经元单元

先在横向记录栏选择一条记录，再使用左侧神经元单元列表：

- **单击**：只打开这个神经元单元，替换当前信号。
- **Ctrl + 单击**：保留已打开信号，并追加这个神经元单元。
- **右键**：打开菜单，可选择**仅打开此单元**、**添加到当前视图**、**从视图移除**或**在探针上定位**。
- **方向键上/下**：在列表中移动键盘焦点。

单击任何已打开的信号，就会把它设为当前聚焦的神经元单元。左侧列表会自动滚动并高亮对应行，探针检查器与下方详细图也会同步切换。当前最多可同时打开十个神经元单元。

列表中的 `Good`、`MUA` 等值是 KiloSort 或人工整理标签。它们本身不能证明细胞类型、记录有效性或生物学意义。

## 4. 阅读信号工作区

每个已打开的神经元单元都有两个对齐的视图：

- 上方放电栅格图用竖线标出单个放电事件的时间。
- 下方曲线显示经过时间分箱的放电频率。

底部概览图压缩显示整段记录，其中的描边框就是上方详细图正在显示的时间段。单击或拖动概览图可以移动详细时间窗。

### 光标模式

把鼠标移到信号上可读取时间，但不会改变视图；页面滚动保持正常。

### 缩放模式

在信号任意区域拖框选择时间段，或用滚轮以鼠标位置为中心缩放。只有当鼠标位于信号内部时才会拦截滚轮；网页其他区域仍然正常上下滚动。

### 平移模式

水平拖动可移动时间窗。鼠标在信号内部时，向下滚动移动到更晚时间，向上滚动移动到更早时间。触控板会使用横向与纵向输入中幅度更大的方向。

### 时间联动与时间独立

**时间联动**会把缩放、平移、返回和重置同步应用到所有已打开的神经元单元。**时间独立**只操作当前聚焦信号。直接做时间对比时使用联动；需要单独放大某个信号时使用独立。

### 同步行为视频

紧凑视频轨道位于神经信号正上方。如果当前记录目录中包含受支持的视频文件，Explorer 会在本机直接打开。也可以使用**连接本地视频**选择其他文件；无法取得受保护的实验室视频时，使用**生成验证视频**。生成的小鼠场地视频是确定性的：帧率固定为 30 Hz，显示准确帧号，并且每五秒出现一次可见同步脉冲。

可以播放、暂停、拖动、改变速度，也可以逐帧前进或后退。启用**跟随信号**后，当前神经时间会保持在可见窗口内。绿色“视频”游标会在所有已打开神经元单元上标出完全相同的神经时间。在光标模式下单击神经图，会反向把视频定位到该时间。

映射状态会区分已验证的逐帧时钟和未验证的手动偏移。修改**偏移（秒）**后，状态会明确变成**未验证 · 手动偏移**。真实实验只有在提供逐帧时间戳、TTL 事件或有来源记录的时钟拟合后，才能标为已验证。

## 5. 解释神经元单元详情

- **放电事件**：分配给该神经元单元的检测事件总数。
- **平均放电频率**：整段记录平均每秒的放电事件数。
- **ISI < 2 毫秒**：相邻放电间隔小于 2 毫秒的比例；只能作为质量指标之一，不能单独作为淘汰标准。
- **时间覆盖率**：记录各时间段中能检测到该神经元单元的比例。
- **KS 幅度**：KiloSort 给出的幅度摘要，其单位依赖当前数据集。
- **KS 污染率**：KiloSort 提供的污染估计（如存在）。
- **幅度稳定性**：相对放电幅度随记录时间的变化。
- **自相关图**：同一神经元单元不同放电事件之间时间差的分布。
- **KiloSort 模板**：最常分配给该神经元单元的模板波形和峰值通道。

这些功能旁边的问号会说明“是什么、怎么看、什么时候使用”。可以用鼠标悬浮，也可以用键盘把焦点移到问号上。

## 6. 使用探针检查器

右侧面板明确分成四层：

- 脑区色带是可选映射文件提供的连续深度区间。
- 淡色通道刻度表示电极采样位置，不是主要交互对象。
- 灰色圆点表示尚未打开但可用的神经元单元。
- 彩色圆点表示已打开的神经元单元，其颜色与中央信号一致。

当前聚焦单元带白色外环、水平深度线和固定标签。鼠标悬浮在标记上可查看神经元单元 ID、物理探针、shank、深度、脑区和通道。单击可锁定标记及其深度；单击 shank 空白处或按 **Esc** 取消锁定。若多个神经元单元在相近深度重叠，Explorer 会弹出一个小列表，而不是让用户猜测圆点含义。

探针上的选择规则与左侧列表一致：单击仅打开，Ctrl+单击追加，右键打开共享菜单。“附近神经元单元”以锁定的探针位置为参考；空间距离接近本身并不代表功能相似。

当前采集中的 `channel_shanks.npy` 表示一根物理探针上的四个 shank。因此检查器显示一个可展开的**探针 1**，其中包含 **Shank 1–4**，不会再把它们标成四根物理探针。未来如果数据确实来自多根探针，必须在 shank 身份之外再提供明确的物理探针身份。

## 7. 脑区映射

KiloSort 输出本身不包含可靠的脑区身份。解剖注释必须作为独立的可选数据提供。兼容的深度映射至少需要：

- `probe` 或 `shank`
- `depth_um`
- `region`

建议同时提供 `electrode`、`atlas_id`、`color`，以及用于特定记录轨迹的 `recording_id`。`MPN` 等脑区缩写和 KiloSort 字段名会按原文件显示，不进行翻译。

当前映射属于电极/深度级元数据。除非提供完整的图谱坐标与配准来源，否则它不等同于经过配准的三维 Allen CCF 轨迹。

## 8. 布局、主题、语言与键盘操作

拖动左侧分隔条可调整神经元单元列表与信号工作区的宽度。探针检查器保持固定宽度，因为横向变宽不会改善深度辨识度。拖动探针图下方的横向把手可以调整图的高度；把手获得键盘焦点后，使用上/下方向键小幅调整，按住 Shift 可大幅调整，按 Home 重置。小屏幕仍可用箭头按钮折叠侧栏。

主题包括深色、浅色、高对比度和跟随系统。主题会同步影响 HTML 界面、信号 Canvas、探针色带、网格、选择框和神经元单元颜色。主题与语言选择都会保存在当前设备。

Explorer 支持 English、简体中文和 Español。切换语言会同时更新界面、问号说明和帮助抽屉。文件名、脑区缩写与 KiloSort 字段名保持不变。

使用 **Tab** 和 **Shift + Tab** 在控件间移动；按 **Enter** 或**空格**激活按钮；按 **Esc** 关闭帮助、菜单、数据状态或已锁定的探针选择（适用时）。

## 9. 隐私与性能

在文件夹模式下，所选文件保留在本机。浏览器只负责索引文件夹；后台处理完成后，界面只接收所选神经元单元的结果。数据库模式可以连接独立运行的本地服务，但它是可选的，直接以 `file://` 打开 `index.html` 时不需要该服务。

帮助说明以 Markdown 保存在仓库中，并在发布前预编译成本地 JavaScript 内容。帮助抽屉不使用 CDN、在线 Markdown 服务或网络请求，因此直接打开 `index.html` 时也可使用。

## 10. 常见问题

- **没有发现记录**：检查每个候选目录是否包含 `spike_times.npy`、`spike_clusters.npy` 和 `params.py`。
- **某个图不可用**：打开数据状态，检查对应源文件是否缺失。
- **脑区显示未映射**：确认文件夹中包含兼容的 Legacy Table 或深度映射，并且记录/神经元单元标识一致。
- **无法查看原始电压**：KiloSort 输出文件夹常只引用外部 `continuous.dat`；Explorer 目前只提供版本化 provider/reader 扩展端口，没有注册 Raw Voltage 实现，也不会把放电时间误标为电压。
- **没有实验室视频**：使用**生成验证视频**即可在不创建、不复制受保护数据的情况下验证播放和准确对齐。
- **导航操作了错误的信号**：检查当前是时间联动还是时间独立，以及哪个信号处于聚焦状态。


## 11. 行为标注测试版

关联视频后选择 **Annotate（标注）**。视频位于可展开时间轴上方，旁边保留神经活动与 Probe。
悬浮时间轴可预览画面而不跳转主视频；滚轮围绕鼠标位置缩放，Shift + 滚轮或位置滑条平移长视频。
拖选区间、选择行为标签后 **Save label（保存标签）**。**Manage labels（管理标签）** 独立管理名称与颜色；
视频角落、时间轴和神经信号遮罩使用同一标签颜色。

选中片段后用 **Play interval（播放片段）** 审核，拖动边界或将播放光标设为起点/终点。
**Fine adjustment · time / frames（精细调整）** 支持秒数或从 0 开始的帧号，结束帧不包含在区间内。
帧号按标称 FPS 换算，变帧率视频请用秒数。**Clip tools（片段工具）** 中保留新建、拆分和移除。
I/O 标记起止、撤销/重做及 Clips & grouping 批量审阅仍可用。
左右拖动 **Speed ×** 数值可每像素调整 0.01，按 Shift 精调 0.001，也可点击输入。
点击神经信号画布内的其他信号行或空白处会恢复折叠，不改变共享时间或标注选区。
操作视频、标注和详情检查器时，当前 Unit 保持展开。

跨组对比时，选择 Unit，待 spike 读取完成后点击 **固定到对比**，再从其他分组或
**查找单元** 加入下一项。最多 6 条固定 spike 行与概览共用时间窗和视频游标；收起分组
不清除固定项。首次固定会把超过 10 秒的视窗缩到游标附近 10 秒。使用光标/缩放/平移
（C/Z/P、+/-）或 **游标附近 10 秒**；× 移除一项，**清空对比** 移除全部。
切换 Recording 或刷新会清空固定项；密集显示时需放大才能辨认单次 spike。

区间统计：在视频时间轴或神经信号上方的彩色行为片段带选择已保存片段，
也可以在信号区域任意拖选时间，再点击左侧 Probe 的 **Interval distribution**。
点大小表示区间 Hz；列表包含全部 Unit 的 Hz 和 spike 数。深度—Hz 统计图默认竖向，
**Horizontal view / Vertical view** 切换坐标轴方向，数值不变；悬浮点可查看详情。
缺少深度的 Unit 仍保留在列表。面板展开时跟随新选区更新，关闭保留选区。
此统计需要本地项目，使用实际覆盖的神经时长和 `[start, end)` 半开区间。

**实验性自动分组** 在本机按运动和画面特征生成候选，可能受位置和光照影响，
尚未验证为可靠的行为识别。选择一组并比较样本视频，再命名分组、确认所选
片段。可将所选片段移入新组以细分或组合分组，也可导入外部算法候选 JSON。
人工调整会保留原始算法组号。

不同 **标签方案** 的名称、分组映射和复核状态相互独立。修改共同的视频边界
会使相关片段在所有方案中重新进入待确认状态。**保存项目** 导出全部方案和
原始算法结果；**导出 CSV** 输出当前方案、映射后的时间和同步状态。草稿会
自动保存在当前浏览器，下载项目文件可获得可迁移备份。未校准的视频保持
“未验证”提示，原始视频和神经数据不会被修改。

## 同时查看两类 Probe 分布

选中行为片段或拖选神经时间段后，打开 **Interval distribution** 查看该区间的 spike count / Hz。
在神经视图、Probe 或统计列表中选择 Unit，再打开 **Unit 模板分布 / Unit template distribution**。两个区域可同时展开，在左侧滚动查看。
模板图的圆点表示电极位置，大小表示该通道的模板峰峰值；点击电极或使用“选择通道”查看波形，各通道使用同一幅值尺度。全部通道列表保留通道行号、可用的采集通道 ID、坐标和幅值。
模板是全记录中该 Unit 最常用的代表模板，显示其对应 spike 数及占比；它不会随时间选区变化，也不是该片段的实测波形。幅值为存储单位，未反白化、未标定为 µV。
切换 Unit 保留时间选区和区间统计；模板缺失或映射不支持时显示原因。Allen 适配数据若没有多通道模板，仍可使用区间活动统计。
